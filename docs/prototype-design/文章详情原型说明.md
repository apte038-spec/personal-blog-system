# 文章详情低保真交互原型说明

日期：2026-10-08；版本：v0.1，14.4设计稿，待用户评审。

## 1. 目标与需求对应

原型：[文章详情原型.html](文章详情原型.html)，PAGE-003，真实路由`/articles/:id`。依据[SRS](../requirements/software-requirements-specification.md)、[权限矩阵](navigation-permission-matrix.md)、[导航设计](navigation-flow.md)。关联BLOG-F-005、BLOG-F-012、BLOG-F-013、BLOG-F-016、BLOG-F-018、BLOG-F-019，BLOG-BR-004、BLOG-BR-005、BLOG-BR-010、BLOG-BR-018、BLOG-BR-019、BLOG-BR-020，BLOG-NF-003、BLOG-NF-010、BLOG-NF-011、BLOG-NF-014。

BLOG-F-013在本原型仅呈现已有统计字段，不模拟真实阅读数写入及相邻文章接口；相邻导航可在后续说明/核对中补充，本轮不声称完整覆盖该需求。全部正文、作者、记录、数量及结果为模拟；网站实现早于原型，不虚构开发历史。

## 2. 布局

公共导航、标题、作者/发布时间/分类/标签、阅读及喜欢统计、正文标题/段落/引用/代码块、喜欢按钮、评论编辑和公开评论。正文为静态手工HTML，用于观察Markdown展示后的结构；不下载Markdown库，不执行外部文章HTML。真实Vue使用marked与DOMPurify，本原型不能验证其净化安全。

返回按钮保留模拟筛选上下文；公共顶部“文章”仍进入默认列表。前者为本轮目标原型设计，不冒充真实详情已存在；不同ID从本地fixture取文章，不从数据库读取。

## 3. 登录与点赞

游客、USER、ADMIN、失效、禁用身份均由控制区模拟。游客尝试互动弹出登录说明，可打开14.3登录原型，也可关闭并手动改为有效用户；不签发Token，不声称14.3登录成功自动返回本文。有效身份喜欢/取消仅改变页面内存和演示数量。操作失败/403模式不改数量、不报告成功；不会调用真实接口。

禁用或失效身份仍可读公开正文，但主动点赞/评论反馈需重新登录或账号禁用；不存在服务端绕过逻辑。403为异常反馈注入，不增加私密文章或其他未批准业务。

## 4. 附带401：重点观察场景

在正常正文状态点击“模拟附带点赞状态401”：身份降为失效，本人喜欢状态未知，正文与公开评论保留，显示适当说明，不进入登录页。随后主动互动仍被拒绝并提示身份要求。

此行为对应BLOG-F-005/BLOG-BR-004的已批准目标。真实[ArticleDetail.vue](../../blog-web/src/views/public/ArticleDetail.vue)调用受保护likeState，[Axios](../../blog-web/src/utils/request.js)全局401跳登录，局部catch不能取消该跳转；原型不表示真实Vue已修复。模拟401处理函数无页面导航调用。

## 5. 评论输入、待审与重复

评论先trim，非空且不超过500字符；本原型沿当前JavaScript字符串长度口径，不擅自将评论改为新密码的码点规则。textarea不静默截断，超过500可观察明确错误。登录后正常提交模拟450ms处理，清输入并显示“评论已提交，审核后展示”；不插入公开列表、不增加公开评论数、不重新读取整篇文章。

当前示例用户曾提交“这篇文章很有帮助。”，按钮可填入并演示重复错误。新内容成功后在本页Set中记为已提交，再次相同内容被拒绝；即使待审也不会成为公开记录。此Set只是同一示例用户/同一篇文章的内存模拟，刷新或切换文件会重置，不能证明SQL唯一约束或并发一致性。切换身份角色不创建第二个模拟用户。

公开评论可切正常（两条APPROVED示例）、成功空集、查询失败，失败数量未知而不是0，正文仍在。保留首字头像，不加入评论分页、图片头像上传、嵌套回复或后台审核按钮；不在此模拟真实审核通过。

## 6. 正文状态与失败

可切持续加载、读取失败、不存在/未发布、403异常状态；非正常状态隐藏正文和互动。未知模拟ID也显示不可读，避免默默替换成默认文章。失败可切回正常；提供返回列表。真实详情当前业务失败后提示并跳列表，本原型留在错误状态以便观察，这是UI设计展示，未改真实行为。

## 7. 运行和检查范围

script语法、本地链接及无真实请求边界在本轮检查；附带401、待审不公开及重复校验进行隔离模拟检查，结果见[使用与核查说明](14.4文章原型使用与核查说明.md)。无真实用户、点赞、评论、阅读统计、JWT或审核操作；没有浏览器验收和原型评审通过记录。Chrome/Edge视觉、弹窗、历史跳转及本期桌面尺寸需后续实测；390px专项仍为后续候选。
