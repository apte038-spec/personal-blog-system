# 后台留言管理低保真交互原型说明

日期：2026-10-09；版本：v0.1，待原型检查。PAGE-014；真实路由：`/admin/messages`。
原型：[后台留言管理原型.html](后台留言管理原型.html)。

## 1. 目标与需求关联

依据[正式SRS](../requirements/software-requirements-specification.md)、[需求清单](../requirements/requirements-inventory.md)、[追踪矩阵](../requirements/requirements-traceability-matrix.md)、[页面映射](page-requirement-mapping.md)。
关联BLOG-F-005、BLOG-F-023、BLOG-F-024、BLOG-F-038、BLOG-F-039；BLOG-NF-002、BLOG-NF-007、BLOG-NF-008、BLOG-NF-010、BLOG-NF-011、BLOG-NF-014；BLOG-BR-004、BLOG-BR-005、BLOG-BR-020、BLOG-BR-021。

留言是站点留言，不关联文章；复用后台三状态审核交互，不增加后台留言发布入口。

## 2. 页面与列表

与14.5-A保持侧栏、顶部、灰阶面板。三张状态统计、内容关键词、状态筛选、当前页选择、每页10条分页。列为选择、用户显示名/用户名、内容、审核状态、时间、审核操作，没有所属文章列。

18条有效内置示例，默认12条待审；加载、成功空、失败和正常分别表达。查询/翻页/状态切换清选择；失败总数与统计未知。示例数据只保存在本HTML内存。

## 3. 审核、反馈及可见性

PENDING为提交初态，目标仅APPROVED/REJECTED；支持单条和当前页批量确认。成功清选择刷新，允许已通过改拒绝及拒绝重新通过。同状态顺序重复幂等成功，不应误认为一定冲突。

整批无效ID或注入失败/冲突时不改变原记录；取消确认不修改；回调一次性消费，防止重复确认。真实网络异步、锁、事务隔离和写入行数并未实现或验证。

公开集合预览仅含未删除APPROVED；PENDING/REJECTED不显示；禁用用户历史通过留言保持可见。该预览不是已制作的公开留言板页面，不调用真实接口，也不与其它HTML数据共享。

## 4. 永久去重演示

工具区固定模拟用户demo4及“历史去重示例”，可切已存在记录为待审核、已通过、已拒绝、历史逻辑删夹具。点击演示均提示重复，记录数保持不变，不能出现“新增成功”或“已提交待审核”的虚假成功。

去重组合是同用户+trim后存储内容，与审核状态无关，没有时间窗口。历史逻辑删除夹具仅说明唯一约束，不提供删除操作。不同用户相同文本不因该组合键禁止，不自行增加所有用户共用内容去重。

原型比较精确字符串，不能模拟MySQL utf8mb4排序规则下的所有等价文本。真实唯一键和重复异常来自schema.sql、InteractionServiceImpl；没有验证实际运行库约束，不能据原型声称去重集成测试通过。

## 5. 删除范围处理

当前SRS BLOG-F-038/039、MessageAdminController、API和Vue均无删除接口/操作。用户于2026-10-09本轮明确选择“保留说明，后续需求变更再处理”。本轮仅保留范围提示，不模拟删除成功或失败，不将REJECTED称为删除，也不批准逻辑/物理删除政策。

## 7. 权限、检查和边界

六身份反馈与其它后台原型一致，非ADMIN不能执行模拟审核或去重工具，隐藏菜单不替代真实授权。内容安全策略禁止连接与表单提交；没有JWT、SMTP、持久存储或真实数据库。

检查记录见[综合说明](14.5-B后台原型使用与核查说明.md)。浏览器页内多选、分页、确认取消、去重工具及桌面视觉未实际验证；也未执行真实系统功能、数据库或并发测试。
