# 后台系统管理低保真交互原型说明

日期：2026-10-08；版本：v0.1，待用户检查。页面：PAGE-015；真实路由：`/admin/settings`。
原型：[后台系统管理原型.html](后台系统管理原型.html)。

## 1. 目标与依据

依据[正式SRS](../requirements/software-requirements-specification.md)、[页面映射](page-requirement-mapping.md)、[权限矩阵](navigation-permission-matrix.md)。关联需求：BLOG-F-005、BLOG-F-031、BLOG-F-032、BLOG-F-040；BLOG-NF-002、BLOG-NF-007、BLOG-NF-010、BLOG-NF-011、BLOG-NF-014；BLOG-BR-004、BLOG-BR-014、BLOG-BR-015、BLOG-BR-024。

分类、标签、站点配置三个局部页签属于同一个路由，不计为三页面。目标是展示维护入口、引用约束、五键字段校验、部分更新与原子保存，不改变正式基线。

## 2. 分类和标签维护

每种各3条模拟数据：启用且被引用、停用且有历史引用、未引用项。新增/编辑用dialog弹窗，删除另确认；启用/停用有确认，状态改变不自动清除历史关联。

分类含name、description、sortOrder、status；标签含name、slug、description、status，真实标签没有sortOrder，原型不添加。标签别名格式及50/80/255长度沿当前DTO；名称/别名重复只做内存精确比较示例，不验证MySQL排序规则、并发或完整数据库唯一约束。

| 删除对象 | 检查目标 | 操作结果 |
| --- | --- | --- |
| 分类 | 有未逻辑删除文章引用，草稿和发布均算 | 拒绝，可停用；仅已逻辑删文章引用不阻止逻辑删分类 |
| 标签 | 有任何仍存在的文章标签关联 | 拒绝，可停用；不因文章状态而忽略仍存关联 |
| 无引用对象 | 通过模拟检查及写入成功 | 逻辑删，列表隐藏，不级联删文章/互动 |
| 目标不存在/失败/冲突 | 模拟异常 | 不报告成功，原数据不变 |

读取状态覆盖加载、空、失败、正常；空为成功返回暂无数据，历史配置缺失提示审计，不自动补默认。读取失败不显示真实空配置，也不提交空状态表单。分类/标签没有虚构分页。

## 3. 五键配置字段规则

| 键 | 用途 | 已批准目标，原型按此模拟 |
| --- | --- | --- |
| siteName | 博客名称 | 非null；首尾U+0000—U+0020去除（Java String.trim口径）后必填；1—50 Unicode码点 |
| siteSubtitle | 副标题 | 非null，允许空字符串，最多100 Unicode码点，不自动trim |
| homeIntro | 首页简介 | 非null，允许空字符串，最多500 Unicode码点，不自动trim |
| aboutContent | 关于我 | 非null，允许空字符串，最多5000 Unicode码点，不自动trim |
| email | 公开联系邮箱，非SMTP账号 | 非null，允许空字符串；非空合理邮箱格式；最多254 Unicode码点，不自动trim |

计数使用Array.from(value).length，不以JavaScript字符串.length冒充码点数。原型邮箱用简单格式表达式作为技术演示，不是完整RFC解析或已批准的最终邮箱校验算法，不进行邮箱投递。没有加入其它正式配置键。

## 4. 部分更新与整批保存

每字段有“本次提交”复选框：

- 勾选键包含在模拟请求内；不勾选为缺失，保持旧值。
- 允许空的四字段明确提交空字符串时保存为空，不能用种子/默认文案替换。
- siteName空字符串或纯首尾空白拒绝。
- 五键null、非字符串、未知键、空对象拒绝。
- 多字段全部合法才生成新配置快照并一次应用。
- 字段非法或模拟中途写入失败：旧配置整个保持，不出现部分成功。
- 保存前、提交内容、保存后三个展示区清楚对照；失败不显示“保存成功”。

JSON演示工具可填单字段、明确空、完整合法批次、未知键、null、混合非法批次、空对象，也可手动填边界值。按钮只是填请求文本，需点击“应用JSON请求”才执行。“批次中途失败”复选框或顶部写入失败注入整批回滚；该原子性是克隆对象后统一应用的内存模拟，不是MySQL事务实验。

表单输入不在保存成功后强行覆盖，便于继续比对；“恢复已保存值”读取当前模拟配置并勾选全部五键，不是补默认。刷新恢复内置夹具，与真实历史非法数据的审批修复完全不同。

## 5. 权限、公开读取边界与异常

三页签只向模拟ADMIN开放。普通用户/角色撤销403；游客、失效、禁用401。没有真实Token或账号。公开读取目标仅五业务键；本原型的已保存展示只包含五键，不提供公开写入口；真实公开读取仍需后端白名单保障，不将系统内部配置全部公开。

批量原子性保留Q12，字段白名单及校验保留Q15/BLOG-BR-024。历史非法/缺失值需要先审计、逐项批准，原型不检查真实库，也不自动改历史内容。

## 7. 检查与待验证

脚本语法、引用、码点/trim/字段边界、部分更新、非法批次与失败回滚的局部检查已完成；详见[核查说明](14.5-A后台原型使用与核查说明.md)。实际浏览器页签、表单、弹窗及桌面视觉尚未核查，真实事务、数据兼容、并发、授权亦未测试。

人工建议：先删“技术学习”和“历史标签”观察拒绝，再删未引用项；切配置页签只勾homeIntro保存；JSON提交空副标题、未知键、null、非法邮箱与合法字段混合；勾中途失败提交合法批次，核对保存前后完全一致；取消失败后正常整批保存。
