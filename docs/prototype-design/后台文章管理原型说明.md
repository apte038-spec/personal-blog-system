# 后台文章管理低保真交互原型说明

日期：2026-10-08；版本：v0.1，待用户检查。页面：PAGE-011；真实路由：`/admin/articles`。
原型：[后台文章管理原型.html](后台文章管理原型.html)。

## 1. 目标与需求关联

依据[正式SRS](../requirements/software-requirements-specification.md)、[页面映射](page-requirement-mapping.md)及[导航设计](navigation-flow.md)。关联：BLOG-F-005、BLOG-F-026、BLOG-F-027、BLOG-F-028、BLOG-F-029、BLOG-F-030；BLOG-NF-002、BLOG-NF-008、BLOG-NF-010、BLOG-NF-011、BLOG-NF-014；BLOG-BR-004、BLOG-BR-010、BLOG-BR-011、BLOG-BR-012、BLOG-BR-013、BLOG-BR-014。

重点沿真实抽屉实现演示创建、编辑、草稿/发布、置顶、逻辑删除和停用历史关联。不是新增文章编辑路由，不提供封面文件上传或回收站。

## 2. 布局、查询与状态

共用后台侧栏和顶部。列表含标题/别名、状态、分类、标签、发布时间、阅读量、编辑/删除；标签来自真实ArticleSummaryVO，但当前Vue列表没有标签列，这一列是本轮目标信息表达，不称现有表格已经展示。

12篇内置文章，每页10条；标题关键词与草稿/发布状态组合查询，查询回第1页。草稿时间显示未发布。读取状态区分正常、加载、成功空数据、失败；失败总数未知，不装作0。“模拟重试”恢复正常。原型列表顺序是内置数组顺序/新增置前，不实现真实updated_at排序及确定性次级排序，也不作为排序验收证据。

写入结果可选成功、失败、重复/冲突；失败留输入及原列表，不报告成功。删除确认可取消，取消不改记录。重复/冲突是演示注入，并非乐观锁新接口。

## 3. 编辑抽屉

新增与编辑共用右侧dialog抽屉，支持标题、别名、摘要、Markdown正文、封面URL、必选分类、可选多标签、DRAFT/PUBLISHED、置顶。取消关闭，不保存。

长度/别名演示沿当前ArticleSaveRequest：标题200、别名220且小写字母/数字/连字符、摘要500、封面URL500；正文必填。除正式配置码点规则外，不自行将所有文章字段长度改成Unicode码点口径。封面仅存表单文本，原型不访问远程图片；正文只编辑文本，不执行HTML。

发布模拟：首次发布给时间，持续发布编辑保留时间，撤回草稿清时间，再发布生成新时间。新增作者及数据库计数由真实后端确定，原型不接受客户端指定他人作者，也不操作真实记录。

## 4. 停用分类和标签关联

| 操作 | 原型目标 |
| --- | --- |
| 新建文章 | 停用分类和标签选项禁用，不允许新关联 |
| 编辑第1篇历史示例 | 其分类2与标签2已停用，但标为原历史关联，保持不变可保存 |
| 编辑其他文章 | 不得新增关联上述停用项 |
| 将旧关联改成启用项 | 可以保存；不是因停用自动删除 |
| 演示工具强行提交停用2 | 按原文章的关联快照重新校验，没有对应历史关联就拒绝 |

演示工具不是正式业务按钮，只用于观察独立校验，不证明服务端已经执行。历史标签原样保留与自动删关联不同；停用状态不会主动修改文章记录。

## 5. 删除规则与反馈

确认成功后设置内存deleted标志，列表排除；清空本篇模拟tagIds，表达真实文章删除时显式清文章标签关系。不是物理删除blog_article。评论、点赞历史保留的规则以说明表达，本原型没有实际评论/点赞记录，不伪造清理验证。

失败、冲突、不存在/已删都不提示成功。已删文章别名仍占用，不能用同别名创建另一条。没有恢复或物理清理按钮。

## 6. 当前代码与目标差异

| 真实文件 | 当前行为 | 原型目标/边界 |
| --- | --- | --- |
| [ArticleManage.vue](../../blog-web/src/views/admin/ArticleManage.vue) | 编辑抽屉；每页10；分类/标签选择未区分停用状态 | 保留抽屉；区分历史选项与新关联 |
| [ArticleServiceImpl.java](../../blog-server/src/main/java/com/example/blog/service/impl/ArticleServiceImpl.java) | 分类仅判断存在；标签统一要求ACTIVE，旧停用标签也被拒绝 | 拒绝新停用关联，允许本篇历史关联不变；尚未修复源码 |
| [ArticleSaveRequest.java](../../blog-server/src/main/java/com/example/blog/dto/ArticleSaveRequest.java) | 字段长度、slug格式、正文和分类非空约束 | 模拟校验并显示集中字段提示；提示文案是设计建议 |
| [ArticleAdminController.java](../../blog-server/src/main/java/com/example/blog/controller/ArticleAdminController.java) | ADMIN接口调用Service；作者取principal | 本地内存模拟，不调用Controller |
| [Article.java](../../blog-server/src/main/java/com/example/blog/entity/Article.java) | deleted逻辑删除字段 | 不描述成物理删除，标签关联是另行清理 |
| ArticleServiceImpl写入 | 当前插入/更新/删除影响行数未系统核对 | 目标失败不报成功；原型不能证明真实写入可靠/原子/并发 |

实际接口：GET/POST `/api/admin/articles`，GET/PUT/DELETE `/api/admin/articles/{id}`；分类/标签读取为GET `/api/admin/categories`及`/api/admin/tags`。前端封装见[blog.js](../../blog-web/src/api/blog.js)。原型没有请求这些接口。

## 7. 权限与检查范围

六身份规则与[概览说明](后台数据概览原型说明.md)一致。非管理员不能执行模拟写入，401/403分别表达；导航隐藏不代替真实后端授权。

已完成脚本语法、本地引用、局部关联规则和隔离模拟DOM检查；未完成真实浏览器抽屉布局、Ctrl多选、焦点/键盘、两个桌面视口及真实业务测试。原型跨文件不共享修改：系统管理原型停用一个项不会自动改变本文列表；本页自带对应停用夹具。

人工建议：查询“历史”→编辑原关联并保存→新增文章尝试强行关联2→观察拒绝→取消；切写入失败再保存/删→原值不变；正常确认删→列表更新。建议截图为文章抽屉、历史关联说明和删除确认，当前无伪造截图。
