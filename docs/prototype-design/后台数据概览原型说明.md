# 后台数据概览低保真交互原型说明

日期：2026-10-08；版本：v0.1，待用户检查。页面：PAGE-010；真实路由：`/admin`。
原型：[后台数据概览原型.html](后台数据概览原型.html)。

## 1. 原型目标与依据

依据[正式SRS v1.0.0](../requirements/software-requirements-specification.md)、[追踪矩阵](../requirements/requirements-traceability-matrix.md)、[页面映射](page-requirement-mapping.md)和[公共布局](layout-design.md)。关联需求：BLOG-F-005、BLOG-F-025、BLOG-NF-002、BLOG-NF-010、BLOG-NF-011、BLOG-NF-014、BLOG-BR-004、BLOG-BR-016。

在既有网站之后补充原型，重点表达统计结果和授权状态，不声称是网站开发前完成的设计。桌面范围为1366×768、1920×1080；BLOG-NF-012窄屏专项不是本期任务。

## 2. 页面布局

沿用AdminLayout左侧六菜单、顶部当前模块与管理员信息、主内容区结构。原型采用与14.3/14.4一致的灰阶、白色面板、细边框、虚线演示区域。管理员展示名为“示例管理员”，不包含真实账号。返回博客只显示尚未制作的首页去向；退出清模拟身份，提供本地登录原型链接。

主区四卡片对应文章总数、用户总数、评论总数、已发布文章；近七日趋势旁展示发布比例与草稿数。“开始写文章”进入文章管理原型，不自动开新增抽屉。趋势以灰阶柱形占位及数值表表达，真实Vue使用ECharts折线；本轮不新增正式统计口径或图表接口。

## 3. 核心状态交互

演示区选择“读取状态”，五种结果明确区分：

| 状态 | 卡片 | 趋势/发布概况 |
| --- | --- | --- |
| 成功非零 | 12篇文章、8用户、6评论、8已发布，均为内置示例 | 七日数量合计8，草稿4，比例约67% |
| 成功真实0 | 正常数值0 | 七日成功返回0；总文章0时比例不适用 |
| 加载中 | 加载中，不显示已经得到0 | 趋势加载，比例未得到 |
| 请求失败 | 查询失败，不回退0 | 趋势失败，比例和草稿未知 |
| 未知/不可用 | 未知 | 不生成伪造趋势或百分比 |

“模拟重试读取”切回正常，未发网络请求。原型统一切换所有读取结果；真实多接口部分失败应按各组件分别表达，精细独立失败控制不在此文件演示。不能把趋势空数组当作成功七天零发布。

## 4. 角色与权限

管理员可查看演示内容。普通用户及角色撤销场景为模拟403，隐藏后台菜单与保护内容，但不将403当作退出；未登录、Token过期、禁用为模拟401，提示清理失效身份并重新登录，公开阅读仍可用。顶部原型工具导航始终可用，只是评审入口，每个文件打开时重新默认模拟管理员，不是业务绕过方案。

菜单隐藏、页面内容隐藏只说明前端设计。每次真实后台请求仍须服务器检查数据库当前角色/状态与有效认证，原型不验证JWT、角色撤销、禁用旧Token不会恢复等安全性质。

| 依据 | 当前静态行为 | 正式目标及原型处理 |

## 6. 模拟边界与检查

全部数值是示例，不是当前数据库统计。脚本和CSS内嵌，无真实Token、API、数据库或浏览器持久存储；刷新复原。静态语法、引用和局部状态检查已完成，详见[综合核查说明](14.5-A后台原型使用与核查说明.md)。浏览器点击、趋势视觉、真实桌面布局、真实统计/鉴权均未验证。
