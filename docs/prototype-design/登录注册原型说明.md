# 登录注册原型说明

日期：2026-10-08。版本：v0.1，14.3低保真设计稿，待用户评审。

依据：[SRS v1.0.0](../requirements/software-requirements-specification.md)、[14.1页面清单](page-inventory.md)、[需求映射](page-requirement-mapping.md)、[14.2导航流程](navigation-flow.md)、[公共布局](layout-design.md)。

入口：[登录注册原型.html](登录注册原型.html)。对应PAGE-006、真实路由 /login，组件位于 views/admin/Login.vue，但普通用户和管理员共用。

## 布局与交互

独立全屏账号卡片，含登录/注册页签；不使用前台导航、页脚。顶部导航与右侧面板是原型工具。登录字段为用户名、密码和忘记密码入口；注册字段为用户名、邮箱、密码、确认密码，不提供管理员选择、昵称或手机号。

| 动作 | 结果与失败路径 | 依据 |
| --- | --- | --- |
| 登录 | 本地检查用户名和非空密码；650毫秒模拟处理中，禁止重复提交；凭证错误、禁用或服务失败留在当前页 | BLOG-F-002、BLOG-NF-010 |
| 登录成功 | 优先演示redirect；否则USER到首页、ADMIN到后台；普通用户/admin被拒并提示首页去向 | BLOG-F-002、BLOG-F-005 |
| 注册 | 用户名trim后非空≤50码点；邮箱trim小写；新密码8–64码点且≤72个UTF-8字节；确认一致 | BLOG-F-001、BLOG-BR-002、BLOG-BR-003 |
| 注册成功 | 模拟USER/ACTIVE，昵称初始化为用户名；切回登录并填用户名、清登录密码，不自动登录 | BLOG-BR-001、BLOG-F-001 |
| 忘记密码 | 打开找回密码原型 | BLOG-F-006 |

旧密码登录不套用新设置规则，不静默截断、不规范化密码。用户名保留大小写及内部字符；唯一性沿数据库比较规则，原型仅注入“重复”结果。ADMIN选择位于明确标识的演示面板，只模拟服务端登录响应角色，不属于注册表单。

## 可复查例子

- 用户名填51个汉字会报错；25个补充平面字符按25码点计数，而非50个UTF-16单元。
- 注册新密码填7个ASCII字符失败，8个可通过长度检查；24个汉字通常为72个UTF-8字节，可过长度检查；25个汉字为75字节，须拒绝。
- 先选重复用户名或邮箱场景，填写合法表单再提交，观察字段错误且输入保留；切回正常场景重试。
- 正常登录选择/profile，可进入个人中心原型；默认无redirect只显示首页/后台目标说明，避免假造本轮之外页面。

这些例子是原型检查建议，非业务系统测试通过证据。已登录访问guestOnly页面的实际重定向机制依赖路由与服务端身份；独立HTML不模拟跨页持久会话。
