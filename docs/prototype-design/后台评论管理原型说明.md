# 后台评论管理低保真交互原型说明

日期：2026-10-09；版本：v0.1，待原型检查。PAGE-013；真实路由：`/admin/comments`。
原型：[后台评论管理原型.html](后台评论管理原型.html)。

## 1. 目标与需求

依据[正式SRS](../requirements/software-requirements-specification.md)、[需求清单](../requirements/requirements-inventory.md)、[追踪矩阵](../requirements/requirements-traceability-matrix.md)、[权限矩阵](navigation-permission-matrix.md)。
关联BLOG-F-005、BLOG-F-018、BLOG-F-019、BLOG-F-036、BLOG-F-037；BLOG-NF-002、BLOG-NF-007、BLOG-NF-008、BLOG-NF-010、BLOG-NF-011、BLOG-NF-014；BLOG-BR-004、BLOG-BR-005、BLOG-BR-019、BLOG-BR-021、BLOG-BR-022。

这是后台跨文章汇总审核，不是单篇文章评论页面。本轮不增加公开评论分页、评论头像上传或审核新状态。

## 2. 布局、数据与查询

共用后台灰阶布局。顶部仅待审核、已通过、已拒绝三张统计卡，没有重新加入“全部评论”模块。列表含当前页选择、评论用户/用户名、内容、所属文章、状态、提交时间及审核操作。

18条有效示例分布于三篇文章，其中一篇标识文章已删除；另有一条历史逻辑删夹具不进管理列表。默认12条PENDING，每页10条；其余为APPROVED/REJECTED。文章不是筛选条件：当前接口仅status与keyword，原型保留内容关键词和三状态筛选，没有凭空增加articleId过滤。

查询、翻页、切状态均清当前页选择；全选仅当前页。已选数量和批量按钮同步，空选择按钮禁用。加载、成功空、请求失败有明确不同文本；失败统计/总数未知而非真实0。

## 3. 单条与批量审核

目标仅APPROVED/REJECTED；PENDING为初始待审，不增加退回待审入口。审核前确认，取消不修改。支持当前页批量通过/拒绝和单条操作；已审可以改为另一状态。确认回调消费一次，不能反复确认造成多次变更。

整批检查1—100条ID、重复ID去重、目标状态和记录存在性；无效目标/记录或注入失败/冲突时整个状态集合不变，不报告成功。成功清选择并刷新，默认待审列表中已审行消失。

重复同状态按幂等成功，不误报“重复请求必定失败”，也不重复增加评论数。工具“状态冲突”是故障结果注入，未批准或实现真实乐观锁机制。

## 4. 公开可见性与评论数量

原型单独显示“公开可见集合预览”，不调用14.4或真实前台：
PENDING/REJECTED不公开；APPROVED且文章有效已发布才公开。文章已删除时其历史评论在后台可识别，但不因此允许访问其公开详情。

通过、拒绝、重新通过后，本地计数按有效文章APPROVED集合重算，用于展示目标不变量与顺序幂等，不复制真实Service增减实现；不证明真实事务/并发安全。已禁用示例用户有历史通过评论，仍显示；禁用不自动拒绝其历史内容。

所属有效文章链接打开本地文章详情原型id1或2（新窗口、noopener）。14.4详情自带独立示例和固定评论，不同步此文件审核结果，不误称端到端联动。已删文章只显示说明，不绕过公开范围。

## 5. 删除范围已确认不扩展

当前SRS BLOG-F-036/037、CommentAdminController、API及Vue均只有查询/统计/审核，没有删除。实体有deleted字段和唯一键，不代表已提供后台删除功能。

用户于2026-10-09在本轮异步澄清中选择“保留说明，后续需求变更再处理”。因此仅提供范围说明，不制作删除确认、删除成功或删除失败流程，不决定逻辑/物理删除策略，不修改正式基线。后续确需删除应单独评估计数、去重、历史留存与权限。

## 6. 当前实现与目标差异

| 证据 | 当前代码 | 原型与后续边界 |

| [CommentManage.vue](../../blog-web/src/views/admin/CommentManage.vue) | 三统计、关键词、分页、多选、单条/批量审核、所属文章新窗口；失败仅提示，初始统计0可能误读 | 原型失败/未知分开显示；保存失败不更改本地状态 |
