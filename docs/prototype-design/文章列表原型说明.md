# 文章列表低保真交互原型说明

日期：2026-10-08；版本：v0.1，14.4设计稿，待用户评审。

## 1. 目标和依据

原型：[文章列表原型.html](文章列表原型.html)，PAGE-002，真实路由`/articles`。依据[SRS v1.0.0](../requirements/software-requirements-specification.md)、[页面映射](page-requirement-mapping.md)、[导航流程](navigation-flow.md)、[布局](layout-design.md)。关联BLOG-F-008、BLOG-F-010、BLOG-F-011、BLOG-F-012，BLOG-BR-010、BLOG-BR-016，BLOG-NF-008、BLOG-NF-010、BLOG-NF-011。它是既有实现之后的目标设计，不是已修复网站或真实接口测试。

## 2. 布局与模拟字段

保持14.3灰阶、细边框、卡片、右侧演示控制区及顶部原型导航。业务框架为公共导航、页面标题、标题搜索、分类/标签、文章卡片、每页8条分页及页脚。18篇内置示例记录均标为模拟，不含真实用户数据、JWT或外部图片。

卡片显示title、summary、categoryName、tags、publishedAt、viewCount、likeCount，封面为占位。这些字段来自当前文章数据模型，不新增数据库字段。现行ArticleCard不显示点赞数，本原型增加已有数据的展示属于本轮UI设计，不称现有卡片已如此呈现。卡片标签保持文字，不新增点击标签跳转。

## 3. 搜索、筛选、分页

搜索匹配标题；分类、标签与关键词组合为交集。搜索、选择分类/标签或改变演示排序回第1页，清除恢复全部条件及基线排序；页码变化保留筛选。共18条示例数据、每页8条可观察3页；某组合可自然产生空结果。输入在DOM中以textContent展示，不插入用户提供的HTML。

右侧“排序观察工具”默认按置顶优先、发布时间降序；最新/热门模式仅用于本轮要求的排序变化演示，非已批准新增列表功能。真实ArticleList没有可选排序，也没有对应sort API参数。模拟同值按ID决胜是本地算法，不代表正式次级字段已经批准。演示参数sort不会发送给真实接口。

## 4. URL与历史恢复

关键词、categoryId、tagId、page以及原型sort/identity写入本地文件query；没有存密码或Token。首次读取有效参数恢复控件/结果；变化用history.pushState建立演示记录，popstate回填并重新计算，方便用户点击浏览器前进/后退。正式需求允许replace，并不要求每次筛选建立历史项。

如果file环境拒绝history API，降级为`#state=`参数及hashchange；没有历史项时先改变两组筛选。异常/超范围模拟参数采用本地安全默认，越界页收敛到模拟结果最大页。这是原型降级约定，不新增真实系统非法query业务规则。

进入详情携带同一白名单筛选参数及模拟文章ID；详情返回列表恢复该上下文。真实详情目前仅顶部文章链接到无query列表，本轮保留上下文的返回按钮是原型设计，不是已实现能力。

## 5. 加载、空、失败与导航

控制区可选正常、持续加载、成功空集、请求失败；失败显示总数未知而非0。公开列表不因模拟身份变为游客、过期或禁用而消失；角色只改变导航身份。ADMIN后台入口显示范围外对话框，不连接后台。

原型导航链接至已有登录、找回、个人中心及另一个文章原型。首页、关于、留言、后台尚未制作，显示真实路由去向说明，不伪造完整目标页面。

## 6. 当前实现差异

[ArticleList.vue](../../blog-web/src/views/public/ArticleList.vue)已读取初始query，并通过replace同步本地条件，但未监听route.query以处理同组件历史回填。加载无局部catch失败展示；原型明确区分失败与空。原型没有修改该文件、[ArticleCard](../../blog-web/src/components/ArticleCard.vue)或[API](../../blog-web/src/api/blog.js)。

## 7. 检查记录与待验证

本轮进行新增HTML脚本语法、引用/ID、网络调用边界及模拟筛选函数检查；具体结果汇总见[14.4使用与核查说明](14.4文章原型使用与核查说明.md)。未执行真实网站/数据库测试，不代表系统历史导航已修复；浏览器视觉、真实地址栏历史及两桌面尺寸仍需人工检查。没有原型评审通过结论。
